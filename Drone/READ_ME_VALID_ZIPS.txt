DRONE FINAL 4K - THREE STANDARD ZIP ARCHIVES

These are normal, standalone .zip archives, not .000/.001/.002 split parts.
All three files are needed to obtain the complete original 4K Webots project.
Each ZIP opens in Windows Explorer or 7-Zip independently.

EASIEST METHOD
1. Download all three .zip files AND Install_Drone_Project.bat and Install_Drone_Project.ps1.
2. Put all five in the same Windows folder.
3. Double-click Install_Drone_Project.bat.
4. The script extracts each valid ZIP into DRONE_READY/Drone and checks all file SHA-256 hashes.
5. Open DRONE_READY/Drone/RUN_DEMO.bat (or hybrid_wheels.bat).

MANUAL METHOD
Right-click each .zip, Extract All, and use the SAME destination folder for all
three. Each archive contains paths beginning Drone/. Do NOT nest them.

confirmed fixed. Actual FAST-LIVO2 SLAM estimation is also not verified.
