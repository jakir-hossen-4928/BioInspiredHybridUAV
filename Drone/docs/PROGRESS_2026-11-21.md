# Technical progress update - Autonomous hybrid drone simulation
Date: 21 November 2026  |  Target academic submission: Friday 27 November 2026

## Summary for the report due today

We developed a Webots R2025a agricultural simulation using a custom quadcopter model, RGB cameras, a generic 3D LiDAR, simulated IMU/GPS/altimeter/ultrasonic inputs, terrain depth mapping, guarded landing decisions, multiple aerial survey points, camera capture, known-map A* navigation and interactive route editing. The drone is controlled kinematically in Webots and does not have a physics-accurate flight controller.

A separate flight/walking **prototype** has now been added. It includes four articulated legs and a diagonal stepping gait, walking between selected waypoints, a depth-checked flight-to-ground transition, an automatic ground-to-flight transition, a heading- and mode-augmented grid A* search, and a simplified ultrasonic response to previously unmapped obstacles. Original flight mission and 4K camera settings are preserved.

**Validation boundary:** 44 automated offline tests passed, including 10 checks on new hybrid code. This is not the same as having run and visually verified the new Webots world on the student's Windows PC. Actual foot-force measurements, FAST-LIVO2 estimated trajectories and the complete Hybrid A* research algorithm are **not yet validated**. The stated completion date of Friday 27 November is a target, not a tested-delivery guarantee.

## Inputs, outputs and test evidence

Inputs include `scene.json`, `settings.json`, route editor JSON, simulated depth/range/IMU/GPS/ultrasonic cameras, and keyboard W/I/D and standard survey controls. Outputs include 4K image captures, survey CSV, terrain height map, Webots labels, hybrid status JSON and ROS2 sensor streams. Offline tests cover planning, known-map clearance, safe landing checks, initial walk to flight, safe/unsafe mode gate, heading-mode transition, leg phase and sensor obstacle response. The new world has not been run or captured in Webots GUI here. Historical farm screenshots and algorithm route previews must be labeled as such.
